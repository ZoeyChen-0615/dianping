# 前端（单文件 SPA）

手机 App 风格的单页应用，直接调用本机后端 `http://localhost:8081`。

## 用法

后端启动后，用浏览器打开 `index.html` 即可（双击用 file:// 打开也行，后端已配置跨域）。

- 右上角 ⚙ 可改后端地址（默认 `http://localhost:8081`）
- 「我的」页用邮箱收验证码登录（验证码从后端日志里看，见主 README）
- 登录态 token 存在浏览器 localStorage

## 功能

- 首页：商户分类 → 商户列表 → 商户详情 → 优惠券 / 秒杀抢购
- 探店：热榜 → 详情 → 点赞
- 我的：邮箱验证码登录、签到、签到统计
